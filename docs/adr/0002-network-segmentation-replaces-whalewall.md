# Network segmentation replaces Whalewall

The threat we care about is lateral movement between Services, not egress. Whalewall (label-driven nftables rules) has had no release since February 2023 and needs a read-write Docker socket. We remove it and instead place Services on purpose-scoped networks: a proxy network for Traefik and the Services it exposes, an internal network per Stack (each app with its Datastores), and a metrics network for Prometheus and its exporters. A backup network, owned by the ops Stack, is joined only by stack-back and the databases it dumps, so the backup tool reaches every Datastore without sharing a network with the apps. Egress is deliberately left unfiltered.

A `downloads` network, owned by the edge Stack so that no app Stack must come up before another, is joined only by the Requesters, Downloaders and Organizers that talk to each other once arr is split. Reusing `proxy` for that traffic was rejected: it would quietly turn the reverse-proxy network into a general network for Services to talk to each other. An exporter that needs a Service's credentials is a sidecar in that Service's Stack, so monitoring never holds every app's keys. A Probe needs no credentials and lives in monitoring, joining the network that gives it the dependent's path.
