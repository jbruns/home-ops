# One Stack per app, each with its own Datastores

The original four Stacks (common, home, media, monitoring) were topical, but network isolation, `depends_on` ordering, deploy blast radius, and backup scope all line up with a single app and its Datastores. We split them into one Compose project per app. The topical folders remain only as Areas. Datastores are never shared across Stacks: Vaultwarden gets its own MariaDB instead of sharing Nextcloud's. Existing named volumes keep their old names (e.g. `home_vaultwarden_data`) via an explicit `name:`, so the split moves no data. Do not "tidy" those names without a planned migration.
